# Игра «21» с дилером — план реализации

> **Для исполнителя:** реализовать план последовательно в текущем репозитории, сохраняя стиль существующих мини-игр.

**Цель:** добавить одиночную игру «21» против дилера с оплатой ставки и отображением карт через Discord Components V2.

**Архитектура:** состояние игры будет описано dataclass и храниться в сервисе до завершения раунда. Сервис будет отвечать за колоду, ход игрока, ход дилера и выплату; View — только за кнопки; Components V2 — только за представление состояния и карт.

**Стек:** Python, disnake 2.11+, Tortoise ORM через существующий economy service, JSON-конфигурация, локальные PNG-ассеты.

**Спецификация:** утверждённое пользователем требование в текущем диалоге.

## Ограничения

- Не добавлять тестовые файлы или тестовые наборы.
- Не использовать embed для игрового сообщения.
- Не зашивать значения карт, названия мастей, пути ассетов, размеры и выплаты в игровой код.
- Сохранять паттерн существующих игр: service + View + interaction routing + локализация.
